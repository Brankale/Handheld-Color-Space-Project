# Handheld Notes

This directory contains the screen data and shaders for the measured handheld consoles.

An entry is included when an additional note has been recorded. Consoles without an entry currently have no additional notes in the project documentation.

## Nintendo

### Game Boy Light (`MGB-001`)

- Uses an EL backlight.

### Game Boy Color (`CGB-001`)

- The currently provided data have issues.

### Game Boy Advance (`AGB-001`)

- The currently provided data have issues.

### Game Boy Advance SP (`AGS-001`)

- The frontlight illuminates the reflective display from the front, but does not make it transmissive or transflective.
- The currently provided data have issues.

### NDS Phat (`NTR-001`)

- Only the backlit mode has been measured.
- Additional information: [transflective display reference](https://www.youtube.com/shorts/QxCrDdIadwU).

### NDS Lite (`USG-001`)

- Greyscale gamma differs between reports, possibly because of different manufacturers.
- Known manufacturers include Hitachi and Sharp. See the [Wired reference](https://www.wired.com/2008/02/sharp-hitachi-s).

### 3DS (`CTR-001`)

- Equal primaries across measurements, except for blue, and similar gamma.

### New 3DS XL (`RED-001`)

- Only the IPS top screen has been analyzed.
- Screen lottery applies to this model.
- Additional information: [Erica Griffin's screen lottery reference](https://www.youtube.com/watch?v=QvDdaVZ7MCU).

### Switch (`HAC-001`, `HAC-001(-01)`)

- Known manufacturer: Innolux.
- Additional information: [Erica Griffin's reference](https://www.youtube.com/watch?v=QvDdaVZ7MCU).

### Switch OLED (`HEG-001`)

- Additional information: [GamingTech's reference](https://www.youtube.com/watch?v=mYnUdYoh_xc).
