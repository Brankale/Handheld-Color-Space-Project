These measurements are work in progress

- spotread must be configured with high precision flag
- measurement conditions must be defined
- black patch is inconsistent between measurements of different color patches. The photometer should probably be calibrated against the white tile before measurements.

NB: data are measured with a colormunki photo
NB: data below 440nm are invalid because of instrument limitations. If you plot the data you get a flat line
NB: reflectance data must be greater or equal to 0. Negative values are not phisically possible.
NB: XYZ values additivity property does not hold. Must be found how light gets reflected when combining R, G and B values

The files in this measurements folder are an elaboration of the measurements in [2026-05-13][Pokefan531]; in practice, these measurements and [2026-05-13][Pokefan531] are almost exactly the same thing and should be merged.
