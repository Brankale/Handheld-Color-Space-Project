# Notes (gbc-rgb 2026-05-04.txt, gbc-ycm 2026-05-05.txt)

This is the same physical GBC previously measured on 2025/10/22.

This report combines preliminary colour-ramp measurements from two acquisition dates:

- `gbc-rgb 2026-05-04.txt`: RGB ramps measured on 2026/05/04. The sequence was interrupted before completion during the yellow ramp.
- `gbc-ycm 2026-05-05.txt`: yellow, cyan, and magenta ramps measured on 2026/05/05.

Noise can affect otherwise uniform dark shades, including non-monotonic values near levels 29-31. The averaged colour dataset from 2026/05/13 supersedes these preliminary colour ramps.

These measurements are referred to -45° orientation (low gamma)



# Notes (gbc-gamma 2026-05-09.txt, gbc-gamma1 2026-05-09.txt, gbc-gamma2 2026-05-09.txt)

This is the same physical GBC previously measured on 2025/10/22.

These are greyscale gamma measurements. The initial acquisition showed that the response varies with the light angle on this reflective screen. It was followed by a rescan in two opposing meter orientations, sampling the highest and lowest gamma responses. Each swatch in the two rescan exports was measured five times because averaging was not available in the meter workflow. The rescan exports are the updated gamma reference for this date.
